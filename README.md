# Mohammed Khalid - Personal Portfolio

This is the source code for my personal portfolio website, built using modern web technologies like React, TailwindCSS, Redux, and Vite. The project showcases my skills, experience, and open-source contributions in a fast and interactive way.

## 🚀 Tech Stack

- ⚛️ React 19  
- 🌬️ TailwindCSS 4  
- 🔁 Redux Toolkit  
- 📦 Vite (for blazing-fast builds)  
- 🔗 React Router DOM  
- 🖼️ React GitHub Calendar (to show GitHub contributions)  
- 🖋️ Lucide Icons + React Simple Icons  
- 🌐 Fullscreen utility (`@thekhalidsha/easy-fullscreen`)  

## 📂 Project Structure

- `/src` - All frontend source code  
- `/components` - Reusable UI components  
- `/pages` - Main sections (Home, About, Projects, etc.)  
- `/redux` - State management using Redux Toolkit  
- `/assets` - Static files like images or icons  

## 🛠️ Development Setup

### Install dependencies
```bash
npm install
```

### Run in development
```bash
npm run dev
```

### Build for production
```bash
npm run build
```

### Preview production build
```bash
npm run preview
```

### Lint the code
```bash
npm run lint
```

## 🌟 Features

- Clean and responsive UI  
- GitHub contributions graph  
- Social media links with brand icons  
- Interactive navigation with React Router  
- Easily expandable and customizable
